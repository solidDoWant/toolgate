These commands are filled in for this gateway. Click Copy next to a command, then paste it in a terminal.

One command (Linux and macOS)

curl -fsSL {{$url}}/install.sh | sh

The script downloads toolgate {{$ver}}, checks its SHA-256 checksum, installs the Claude Code plugin when claude is present, and saves the gateway URL. You can read it first: curl -fsSL {{$url}}/install.sh | less. To see what it would do without changing anything, add -s -- --dry-run after sh.

Step by step

Use these commands if you do not want to pipe a script to sh. Replace linux-amd64 with linux-arm64, darwin-amd64 or darwin-arm64 to match your system.

  1. Download the command and the checksums: 
    curl -fsSLO https://github.com/solidDoWant/toolgate/releases/download/{{$ver}}/toolgate-linux-amd64
curl -fsSLO https://github.com/solidDoWant/toolgate/releases/download/{{$ver}}/checksums.txt
  2. Check the download. The output must say OK: 
    grep ' toolgate-linux-amd64$' checksums.txt | sha256sum -c -
    On macOS, use shasum -a 256 -c -.
  3. Install it in a directory on your PATH: 
    install -m 0755 toolgate-linux-amd64 ~/.local/bin/toolgate
  4. Add the plugin marketplace and install the plugin: 
    claude plugin marketplace add solidDoWant/toolgate
claude plugin install toolgate@toolgate
  5. Set the gateway URL: 
    echo '{"gateway_url":"{{$url}}"}' | claude plugin configure toolgate@toolgate --values-stdin
toolgate configure --gateway {{$url}}
  6. Sign in: 
    toolgate login

Windows

In PowerShell, download the command and check it. Use arm64 instead of amd64 on an ARM PC. Then put the file in a directory on your PATH.

Invoke-WebRequest https://github.com/solidDoWant/toolgate/releases/download/{{$ver}}/toolgate-windows-amd64.exe -OutFile toolgate.exe
Invoke-WebRequest https://github.com/solidDoWant/toolgate/releases/download/{{$ver}}/checksums.txt -OutFile checksums.txt
(Get-FileHash toolgate.exe -Algorithm SHA256).Hash
Select-String toolgate-windows-amd64.exe checksums.txt

The two hashes must match. Then run the plugin, gateway URL and sign-in commands from the step by step list.

Check that it works

toolgate status

Then start Claude Code and run /mcp. The list must show toolgate with its tools.

Workspace defaults

A new user sees no servers until they set the workspace defaults. Run this to allow the servers that your admin offers. The command prints a link; open it and approve the change:

toolgate workspace defaults --verified all
